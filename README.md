# Robert Mullen portfolio

This is a static site. Open `public/index.html` to preview it locally.

## Deploy with Netlify

1. Extract the ZIP and commit the contents of the extracted folder to the root of your Git repository.
2. Import that repository in Netlify, or connect it to your existing Netlify project.
3. Leave the build command blank. The publish directory is `public`, as set in `netlify.toml`.

Edit `public/index.html` for copy and links, `public/style.css` for the design, and `public/media/` for images. The legacy `/featured-projects.html` URL redirects to the Selected work section.
